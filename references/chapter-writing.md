# Chapter writing

## Context pack

Load active constraints, previous chapter, summaries for the recent relevant range, current event plan, participating character states, open threads, timeline anchors, and accepted changes. Use `novelforge.py context` when files exist. Do not load the whole manuscript to continue one scene.

## Internal task card

Define objective, opening continuity, viewpoint, time/place, participants, knowledge boundaries, required beats, props/clues, emotional turn, ending state, target length, and prohibited outcomes.

## Drafting

Start from the live consequence of the previous ending. Each scene needs a local desire, resistance, meaningful change, and reason to exit. Dialogue should answer, evade, pressure, misread, bargain, or reveal; avoid queued explanatory speeches. Use action and selected detail instead of restating emotions.

Maintain requested completeness. Do not replace a requested full chapter with an outline or sample. If tool counting differs from a platform counter, report the convention.

## After drafting

Check continuity, causality, knowledge, scene function, repeated beats, pacing, ending promise, and length. Propose state updates and a factual summary; write them only when authorized or when project maintenance is explicitly included.
